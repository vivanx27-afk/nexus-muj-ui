# 🚀 Nexus Club - MUJ Website

A modern, high-energy landing page for **Nexus**, the official tech and innovation club of Manipal University Jaipur (MUJ). Built with pure HTML and CSS, featuring a sleek dark-mode aesthetic, glassmorphism UI, and vibrant glow effects.

---

## ✨ Features

* **Sleek Dark Theme:** Tech-focused palette using deep blues, electric purples, and cyan accents.
* **Glassmorphism Navbar:** Floating frosted-glass navigation bar.
* **Pure CSS Ambient Glow:** High-performance background glow effects without heavy images or JavaScript.
* **Fully Responsive Layout:** Clean typography and flexible layout for modern Web display.
* **Lightweight:** Zero dependencies, framework-free, and lightning-fast load speeds.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure.
* **CSS3:** Custom styling, CSS Grid/Flexbox, dynamic gradients, and backdrop filters.
